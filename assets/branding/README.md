# Your Voice brand assets

The SVG files are editable masters. PNG and JPG exports are ready for upload. The graphics use
the same speech and waveform mark, dark blue background, and teal accent as the application.

| Asset | Dimensions | Suggested use |
| --- | --- | --- |
| [Social landscape](social-1280x720.png) | 1280 × 720 | 16:9 post or video cover |
| [Link preview](social-1200x630.png) | 1200 × 630 | Open Graph card or landscape post |
| [Wide header](header-1500x500.png) | 1500 × 500 | Profile banner |
| [Square post](square-1080x1080.png) | 1080 × 1080 | Square feed post |
| [Portrait post](portrait-1080x1350.png) | 1080 × 1350 | Portrait feed post |
| [Story](story-1080x1920.png) | 1080 × 1920 | Story or short video cover |
| [Profile image](avatar-400x400.png) | 400 × 400 | Social profile image |

The [favicon SVG](favicon.svg), [32 px PNG](favicon-32.png), [ICO](favicon.ico), and
[Apple touch icon](apple-touch-icon.png) match the app icons in `frontend/public/`.

Run `python assets/branding/generate.py` from the repository root to regenerate the SVG masters.
If you change an SVG, export the matching PNG and JPG at the dimensions in this table.
